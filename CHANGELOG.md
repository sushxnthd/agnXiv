# Changelog

All notable changes to AgnXiv are documented here. Releases use stable Semantic
Versioning and are cut only from verified commits merged into `main`.

## [0.1.0] - 2026-10-19

### Added

- Evidence-bound claim verification with zero-manifest and manifest workflows.
- Conservative locator discovery and abstention behavior.
- Signed in-toto/DSSE verification statements and issuer-key rollover metadata.
- Append-only transparency ledger and content-addressed evidence capsules.
- Crossref/DataCite publication identity binding.
- Ephemeral hosted-worker sandbox boundary, security scanning, operational SLOs,
  PostgreSQL recovery drills, and cross-region failover validation.
- Frozen scientific validation gates for false-pass control, central-claim
  routing, and historical environment recovery.
- Reproducible release build, checksums, SBOM, provenance attestation, and
  release-contract automation.
