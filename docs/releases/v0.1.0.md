# AgnXiv v0.1.0

This is the first production-oriented public-beta release of AgnXiv.

AgnXiv turns computational research claims into executable, content-bound
verification records. This release includes the zero-manifest verification
path, evidence-bound numerical verdicts, signed in-toto/DSSE provenance,
append-only transparency and evidence archives, DOI registry binding,
production sandboxing, operational recovery controls, and the frozen
scientific validation suite.

## Release integrity

The release workflow rebuilds Python artifacts twice and requires byte-identical
hashes, reruns the full test and scientific safety suites, scans the service
image for HIGH/CRITICAL vulnerabilities, generates a CycloneDX SBOM and
SHA-256 checksums, and emits GitHub artifact provenance attestations.

This release remains scoped to claim-level computational evidence. It does not
certify universal paper truth, novelty, importance, or publication quality.
