## RedBench v0

Six adversarial recorded-output cases:
- matched expected state: 4/6
- false passes: 0
- false contradictions: 0
- abstentions: 5/6
- decision coverage: 1/6
- false-pass rate: 0%

Two cases expected a recoverable contradiction but AgnXiv abstained instead. This is a safe failure mode but demonstrates low semantic-locator coverage.

Interpretation: the current observation selector is conservative on this small adversarial set. Six cases are far too few to establish a production false-pass rate.

## Cross-domain ingestion

The first non-arXiv Scientific Data case failed before claim analysis because the supplied publisher PDF URL returned HTML rather than PDF bytes.

Interpretation: paper materialization is itself a cross-domain bottleneck. The diagnostic downloader is being upgraded to validate PDF bytes and resolve standard `citation_pdf_url` metadata.
